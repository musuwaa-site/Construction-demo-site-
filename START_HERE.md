# Imara — Tanzania Construction Demo

A premium construction company demonstration website, made for Dixi to personalise for different clients.

## Open the website

Open **index.html** in a modern browser. All seven photographs, styles and website code are embedded in this one file. The website itself needs no external fonts, image servers, installation or build step.

If your Android file manager opens a basic HTML preview that does not run the editor, open the hosted GitHub Pages version in Chrome or Samsung Internet instead. External links, WhatsApp and email require the relevant app or internet connection.

## Personalise a company

1. Press **Demo Studio** in the bottom-right corner.
2. In **Brand**, change the company name, descriptor, colours, office details, email and WhatsApp number. Upload a logo, or keep the architectural monogram. Three fictional brand presets give you quick starting points.
3. In **Content**, change the headline, introduction, about section, services, process, frequently asked questions and contact copy. Replace the hero, about and wide photographs here.
4. In **Gallery**, upload multiple project photographs together. Edit each title, description, location, category and photo credit. Tick **Feature on the main page** for your favourites. Use Move up/down to reorder the collection. Every image remains available in the full gallery.
5. Press **Preview website** to close the editor. Press Demo Studio to continue editing.

Uploads support JPG, PNG and WebP, up to 20 MB per original image and 40 images in one batch. Photos are resized automatically. Smaller originals improve performance on modest phones. JSON imports support up to 300 gallery items and 50 MB total.

## Keep several client versions

Open **Demo Studio → Save & export**. Type a profile name and press **Save current company as a profile**. Save the current company before loading another profile if you want to keep it.

Profiles and edits save in this browser’s storage. They do not sync between your phone, tablet and PC. Clearing browser data can remove them. If storage is unavailable, the editor says it is a temporary session. Export HTML or a company backup to preserve your work.

**Important:** local browser edits do not update GitHub or another visitor’s page.

## Download a personalised website

In **Save & export**, select whether to include Demo Studio, then press **Download customised HTML**. The resulting **index.html** contains this company’s current details and images, ready to share or upload.

Turn off “Include Demo Studio” for a cleaner client presentation. This only hides the button. It is not a password-protected admin area. Add **?edit=1** to the end of the page URL to reopen the controls. Editing still affects only that visitor’s local browser until a new HTML export is published.

For a transferable backup, use **Download company backup**. Import that JSON file into this template on another device. Backups contain company details and photos, so share only the intended client’s backup.

## Host on GitHub Pages

Use the website or a desktop browser view on your tablet/phone if GitHub hides controls.

1. Sign in to GitHub and create a repository such as **construction-demo**. For GitHub Free, use a **public** repository for Pages hosting.
2. Extract this ZIP first. On the repository’s Code page choose **Add file → Upload files**. Upload **index.html** into the repository’s top level, then commit the change. You can also upload this guide and PHOTO_CREDITS.md. Do not upload just the ZIP: GitHub Pages needs the extracted index.html.
3. Open the repository’s **Settings → Pages**.
4. Under **Build and deployment**, set **Source → Deploy from a branch**.
5. Choose **main** and **/(root)**, then press **Save**.
6. When deployment completes, open the site link shown on that Pages screen.

For later updates, export your customised page and replace the repository’s **index.html**. If a download is named index (1).html, rename it to **index.html** first. Commit the update. Refresh the hosted website after deployment.

GitHub instructions checked against official documentation on 23 October 2026:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Enquiries and WhatsApp

The contact form prepares a message for review. It never sends automatically and has no server or enquiry database. Visitors can copy the message. A real WhatsApp number or email entered in Brand enables the relevant sharing option. WhatsApp numbers need a country code and digits only, without spaces or +. The receiving person must still press Send in WhatsApp or their email app.

The initial phone and email are deliberate placeholders; no sample enquiry is sent to someone else.

## Photography and truthful demonstrations

The company names are fictional demonstration identities. Seven genuine photographs of architecture and urban development in Dar es Salaam are included as references. No contractor, pictured company or photographer is represented as a client or endorser. They are not a record of Imara’s completed projects.

Photo credits appear inside the website and in PHOTO_CREDITS.md. Replace the images with your client’s approved photos and update the sample descriptions before presenting the work as that client’s actual portfolio. The included imagery is used under the Unsplash License; the template’s code is separate from those image rights.
